# PrivateClass

## Test
Create one Teacher account and one Student account in the same browser.
Because this prototype uses localStorage, both accounts and the meeting data are stored in that browser.

Teacher:
1. Sign up as Teacher.
2. Create a meeting.
3. Copy the meeting code.

Student:
1. Sign up as Student.
2. Enter the meeting code.
3. Request to join.

Teacher:
1. Refresh the dashboard if necessary.
2. Accept the student.
3. Enter the meeting.

Student:
1. Refresh the dashboard.
2. The Join Meeting button appears after acceptance.

## Important
This is a working front-end prototype. It does not yet provide real multi-user internet video calling. The meeting page currently activates the local camera/microphone and screen sharing. A real production version needs a backend/database and WebRTC signaling server.
